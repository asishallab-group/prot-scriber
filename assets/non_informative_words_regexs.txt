# Words that carry no meaning of their own. Such a word is not counted when word frequencies are
# taken, so it can never be the reason one description is chosen over another -- but it IS kept in
# the description that wins, because what prot-scriber assigns is a HUMAN READABLE description and
# these are the words that make one read as English. Without them 'hva protein' is 'hva' and
# 'ran binding protein' is 'ran binding', which are not descriptions.
#
# FORMAT. One expression per line and nothing else -- no replacements, no continuation: an
# expression never spans lines. A line whose first non-blank character is '#' is a comment,
# and a blank line is nothing. An expression may still match a literal '#'; write it as
# '[#]', which no regex dialect can read as anything else.

# Function words.
(?i)\bthe\b
(?i)\band\b
(?i)\bor\b
(?i)\bfrom\b
(?i)\bto\b

# Words that say a protein is a protein.
(?i)\bmember\b
(?i)\bprotein\b
(?i)\bgene\b

# A database name that ends up in descriptions.
(?i)\btair\b

# A bare number. Note that a standalone number is usually removed before this by the
# capture-replace pairs; what reaches here is one that was part of a compound token, such as the
# '20055' of 'KLMA_20055' once the splitting expression has cut it at the underscore.
#
# ANCHORED, and it has to be: the word must BE a number, not merely contain one. A word boundary
# sits either side of the tilde in 'duf~4228', the sentinel a domain accession is joined with, and
# an unanchored rule reads the '4228' through it and calls the whole accession uninformative.
^\d+$
