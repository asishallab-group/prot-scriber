# Pairs of lines rewriting a sequence title before it is scored: the first line of a pair is a
# regular expression (fancy-regex syntax, so back-references work), the second is what to replace
# what it matched with. They are applied in order.
#
# FORMAT. Lines in PAIRS: an expression, then the replacement below it. (The other seven shipped
# lists are not paired -- they are one expression per line. Only these two capture-replace
# lists take a replacement.) An expression never spans lines.
#
# A comment is always ignored, and so is a blank line -- EXCEPT the line directly after an
# expression, which is that expression's replacement whatever it contains. A blank one there
# means 'delete what matched', and one holding a single space means 'replace it with a space';
# the pairs below use both. So leave no blank line between an expression and its replacement,
# and put them between pairs freely. Write a literal '#' in an expression as '[#]'.

# A domain or database accession, so that 'DUF1234' and 'DUF 1234' become one word rather than
# two, and the number stays attached to the family it names.
(?i)\b(?P<first>duf|pf|ipr|pthr|go|kegg|ec)(?P<second>[0-9:]+)\b
$first~$second

# A trailing copy number on a gene name, so that ADH1 and ADH2 agree on 'adh' and reinforce each
# other's count. THREE letters at least: with two it destroys the name instead, because CD5, VP2,
# UL6, GP4, IF3 and SH3 are names in which the number IS the identity.
(?i)\b(?P<first>[a-z]{3,})[-.,\d]+\b
$first 

# A number standing on its own between spaces. Note what this cannot reach: a number that only
# becomes standalone once the description is split, such as the '20055' in 'KLMA_20055'. Those are
# removed at the token by the filter lists.
(^|\s+)[-.\d]+(\s+|$)
 

# A locus code sitting inside a real description -- 'Vacuolar membrane protein ZYRO0A01628g',
# 'UPF0768 protein C1952.04c'. The blacklist cannot reach one, because it discards a WHOLE
# description and so is anchored; this deletes the code and keeps the description around it.
#
# A RUN of four or more digits is what marks an identifier: Swiss-Prot's vocabulary holds 1,793
# words of this shape and 1,769 are seen exactly once, while a gene name like SLC25A24 or C18orf32
# has no such run and is left alone.
#
# ORDER MATTERS, and it is why this sits below the three rules above rather than beside them. The
# accession rule's tilde is what keeps DUF4228 and PF01234 out of its reach, and the copy-number
# rule has by then turned UPF0768 into 'upf' -- a family prefix worth keeping, and one this rule
# would otherwise take away with the number. It stays above the space-run rule, which is what
# clears up after it.
(?i)\b[a-z][a-z0-9.]*\d{4,}[a-z0-9.]*\b


# A word repeated later in the same description, keeping the first and what lies between.
(?i)\b(?P<first>\b\w+\b)(?P<spacer>.*)\b\k<first>\b
$first$spacer

# The runs of spaces the rules above leave behind.
\s{2,}
