# Substrings deleted from a sequence title before it is scored, applied in order.
#
# THIS LIST IS FOR UniProtKB -- Swiss-Prot and TrEMBL -- whose titles read
# 'sp|P12345|ADH1_ARATH Alcohol dehydrogenase 1 OS=Arabidopsis thaliana OX=3702 GN=ADH1 PE=1 SV=2'.
# The accession rule and the 'OS=|OX=|GN=|PE=|SV=' rule below are that shape and no other's.
#
# IT IS ALSO WHAT A TABLE THAT NAMES NO LIST IS GIVEN, which is the thing to know about it: on
# results from a database whose titles have another shape it is worth 0.156 precision and 0.104 F1
# (measured over 1,215 gene families, 27.08.2026), because what it fails to strip becomes words.
# NCBI's NR, NCBI's RefSeq, the PDB and the UniRef databases each have their own list -- run
# 'prot-scriber defaults' to see them, and give one as '--db-filter <table>=@NAME'.
#
# FORMAT. One expression per line and nothing else -- no replacements, no continuation: an
# expression never spans lines. A line whose first non-blank character is '#' is a comment,
# and a blank line is nothing. An expression may still match a literal '#'; write it as
# '[#]', which no regex dialect can read as anything else.

# RefSeq marks a suspect translation this way.
(?i)low\s+quality\s+protein:

# A UniProt tail, from whichever of its tags comes first. `OS=` alone is not
# enough: the organism-bracket rule below can take that part off first and
# leave `OX=... PE=3 SV=1` behind.
(?i)\s(OS|OX|GN|PE|SV)=.*$

(?i)OS.*[.].*protein

# An artefact of some Blast databases: a title beginning `H0` and running
# to the word `protein` carries no description.
(?i)^H0.*protein

# `... contains ...` introduces a domain listing, not a name.
(?i)contains.*

# An InterPro accession and everything after it.
IPR.*

# A UniProt identifier, `sp|P12345|ADH1_ARATH`.
\b\S+\|\S+\|\S+

# A locus code of the Arabidopsis kind -- At2g26220, Os03g0234400 -- where a
# letter for the chromosome sits between two numbers.
\w{2,}\d{1,2}[gGmMcC]\d+(\.\d+)*

# A systematic locus tag -- KLMA_20055, DDB_G0273761, TTV12_gp3. A digit is
# what makes it an identifier rather than a word, so CSB_alpha is left alone.
# Removed whole because the splitting expression would otherwise cut it at the
# underscore into two words, one of them a bare number.
\b(\w*\d\w*_\w+|\w+_\w*\d\w*)\b

# A molecular weight. It is a measurement, not a name.
(?i)\b\d+(\.\d+)?\s*kda\b

# A bracket that opens straight after a word, and everything after it.
\b\[.*

# A description made of nothing but punctuation, whitespace and digits.
^(\s|/|\(|\)|-|\+|\*|,|;|\.|:|\||\d)+$

(?i)\bunknown\b

(?i)-?\blike\b

(?i)\bsimilar\b

(?i)\bpredicted\b

(?i)\bputative\b

(?i)\buncharacterized\b

(?i)\bprobable\b

(?i)\bcontig\b

(?i)\brelated\b

(?i)\bremark\b

# An open reading frame number -- ORF, ORF1, c15orf -- which names a position
# in a sequence and not a function.
(?i)\b\w?orf(\w?|\d+)\b

(?i)\bisoform\b

(?i)\bhomolog\b

(?i)\bfragment\b

(?i)\bblast:\b
